# 本番候補・公開差分・復旧パッケージ（2026-10-28）

## 公開中ゲームの確認

本番の math.html / japanese.html / social.html / language.html の公開HTMLからリンクを読み取り、8ゲーム（keisan、distribution、distribution2、exchangeAssociation、kotowaza、pref-name、pref-place、alphabet）を確認した。environments/production-inventory.json に保持し、既存ゲームが本番候補から消えると準備処理を停止する。かけ算のせいしつ・図形と式は候補へ追加していない。

## 一括準備

`npm run prepare:release`

共通ソースから両環境を生成し、`.release/site-package/` に次を作る。

- RELEASE.json：ゲーム対応、保存方法、参照Rulesのハッシュ、公開差分全ファイル、変更前後ハッシュ、停止理由、パッケージ全体のハッシュ。
- forward/：変更ファイルと不足する承認済み素材。
- rollback/：変更前ファイルの原本。新規追加ファイルはmanifestで識別する。

管理室・認証画面・QA・問題確認一覧・未承認ゲームは児童用公開パッケージから除外する。公開中ファイル、Firebase、児童データへはアクセスも書き込みも行わない。公開HTMLの読取による一覧確認は別途実施済み。

## 現行Rulesとの整合

ユーザーが公開・実環境0記録テストを確認した分配専用Rulesを入力とする（Consoleから独立取得したものではない）。keisan/pref-name/pref-place/alphabet/distributionの共有ランキング5項目は許可済み。distribution2/exchangeAssociation/kotowazaは端末保存を維持し、共有ランキングへ送信しない。この3項目の共有ランキングを将来有効にするには、それぞれのBestStreak許可追加を別途承認・Emulator検証する。今回Rules変更は不要。

## ポイント互換

ことわざの旧 mgl_kotowaza_points_v1 の残高・日別上限を新規共通ウォレットへ引継ぐ。旧データを削除しない。共通保存から旧形式残高も更新し、旧クライアントの同時更新を検出した場合は停止する。変更は取引ジャーナルから復旧できる。既に存在する共通ウォレットと旧国語残高の統合が不明確な場合は、自動加算せず安全停止する。

## 公開・復旧ゲート

現候補はruntimeBlocked=true、既存ランキング用サービスも無効のため、そのままの公開は禁止。これらは単なる一般プレイヤー同期とは別のゲートで、今回は解除していない。将来の公開承認後、承認済み環境設定から候補とパッケージを再生成し、新しいpackageDigestに対する承認を受ける。

release-package.mjs のapply APIは `{packageDigest, action:'publish'}` または復旧時の `action:'rollback'` が一致する場合だけ処理する。公開用の一時チェックアウトは `.release/` 内に限定する。全ファイルの現在ハッシュとパッケージハッシュを検査してから一括反映する。差分・改ざん・未承認・未解決の停止理由があれば書込み前に拒否する。このAPIはネットワーク公開しない。検証済みの一時チェックアウトをレビューして、承認されたGitHubコミットとして公開する。

復旧は対象コミットの次に別更新がないことを確認し、同じパッケージのrollbackで変更前ファイルへ戻す。追加ファイルだけを除去し、Firebaseデータや端末保存を削除しない。別更新があれば自動復旧を拒否する。本番Rulesはサイトの復旧とは切り離し、分配フィールド許可を残す（旧Rulesへ丸ごと戻すと追加済みフィールドのある児童文書の保存が拒否されるため）。
