# 平行な2本を見つけよう！ — 第1段階

## 遊び方・確認方法

- 確認用ページ: `preview/games/parallelPair.html`。既存の算数メニューや公開設定は変更していないため、直接このURLを開く。
- 共通ソースをHTTPで配信する場合: `shared-src/site/games/parallelPair.html`。
- 単体HTMLの作成: `node tools/build-parallel-standalone.mjs /absolute/path/parallelPair-review.html`。Chromeで開くだけで遊べる。外部通信は不要。
- 7本から2本を直接タップし「決定！」。再タップで解除。3本目は選択しない。交点で距離が同じ場合は選択せず、別の場所をタップするよう案内する。
- 不正解は選択解除、連続正解数を0にし、同じ図で再挑戦。最高記録は保持する。
- 正解は既存の無音の紙吹雪演出を再利用し、500msのタイマーで次の問題へ進む。
- 初級0〜4問、中級5〜14問、上級15問以降。称号・120秒・ランキングは未実装。

## 数学・配置の検証

`parallel-model.js` が整数の始点・終点を作り、この同じ値をSVG描画・タップ距離・正誤判定に使用する。平行の条件は方向ベクトルの外積が **厳密に0** であること。同一直線上の2本を正解にしない。

出題前に必ず21組全部を検査し、平行な組が1組のものだけ採用する。別の正解インデックスや近似角度を判定の根拠にはしない。回答時も21組を再検査する。

数学検証後、次の条件をすべて満たす問題のみ表示する。

- 全7本が画面内の整数座標、各長さ450以上（1200×680の座標系）。
- 平行な2本の支持直線間距離105以上。
- 非平行な方向の角度差12度以上（上級も10度以上）。
- 線分の内部に5個以上の交点。交点の広がりは横380・縦190以上。
- 交点同士42以上、端点と別の線22以上離す。
- 全ての線に、他の線から32以上離れた連続112以上のタップ区間がある。

不合格は破棄して再生成する。1600回で打ち切り、同じ検証を通す既知のレイアウトを使うため、乱数が偏っても無限ループや不正確な出題にはならない。

## ポイント・データの範囲

既存 `economy-core.js` の `initial` / `reward` / `dayKey` を再利用する。第1段階では専用のローカル記録 `manabi_parallel_stage1:v1` に、連続正解・最高記録・算数のポイント・日別上限・直近128件の重複防止IDをまとめて保存する。

既存の算数残高には合算しない。画面に「このゲームの分」と明示する。正解1pt・ゲーム単位で1日50pt、日付は日本時間。Web Locksがある環境では同時更新を直列化。保存容量不足・保存不可でもメモリに退避して継続できる。これはブラウザを閉じるまでの記録となり、画面に案内を表示する。

Firebase SDK・既存のポイントランタイム・プロフィール・ランキング・公開可否判定・120秒ランタイムは読み込まない。ページのCSPも `connect-src 'none'` とする。Rules、環境設定、本番ルート、公開スイッチ、PR #42は変更していない。
