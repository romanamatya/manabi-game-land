# 平行な2本を見つけよう！ — 第2段階（称号）

## 実装

第1段階の問題生成・全21組の平行判定・選択操作をそのまま使用する。

|連続正解|称号|
|---|---|
|3|平行みならい|
|5|平行ハンター|
|10|平行マスター|
|15|平行の達人|
|25|平行の王者|

`parallel-local.js` の `titles` が条件・名前・画像指定の正本。従来の `manabi_parallel_stage1:v1` に最高記録と獲得称号IDを保存する。過去の最高記録がある場合は、対応する称号を下位から順に引き継ぎ、過去分の獲得演出は再生しない。既存のポイント・日別上限・直近128件の重複防止IDは維持する。回答履歴・集計は追加しない。

不正解では連続正解数を0にし、最高記録と獲得済み称号を保持する。同じ問題に再挑戦できる。称号は初回獲得時のみ演出し、取り直しでは演出しない。Web Locks利用時は獲得更新も既存の保存と同じロック内で行う。

共通の無音演出に `showTitle` の明示呼び出しを追加。通常正解は500msで次問、称号獲得時は中央の称号名・光・紙吹雪を1000ms表示してから次問へ進む。演出中は選択・決定を受け付けず、装備ダイアログは表示しない。左側には5段階の獲得状況を表示する。

## 不足素材

PR #43のブランチには、平行ゲームの採用済み正式イラスト5点が存在しない。各称号の `image:null` は素材未設定を明示し、他ゲームの画像・汎用バッジ・代替画像は表示しない。称号名と共通演出のみ動作する。正式素材が揃ったら、この5つの画像指定を設定する。
