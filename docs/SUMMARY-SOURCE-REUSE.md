# 計算のきまり・総まとめ：元ゲームの出題処理を再利用

対象は確認用 `preview/` のみ。本番ゲーム・Firebase設定・児童データ・素材PNGは変更していません。

## 原因と修正

以前の総まとめでは「計算のきまり」「分配①」を別生成し、「分配②」に元ゲームにない計算段階を追加していました。かけ算も現在公開中の専用モデルではなく旧モデルを参照していました。数学的に正しいだけでは、元の数値条件や学習目的を引き継げていませんでした。

修正後は既存6ゲームの問題生成関数・問題バンクを直接利用します。元の共有モデル5ファイルは無変更です。計算のきまりだけはHTML内の関数を一字一句同じ内容で共有JSに抽出し、元ゲームと総まとめの両方から呼び出します。

### 修正後の実例

- 計算のきまり：`5×11＋3－2` → `55＋3－2` → `58－2`。各段階で左端の演算が正解。
- 分配①：`99×8` → `(100－1)×8` → `100×8－1×8＝800－8＝792`。元の4択を両段階で維持。
- 分配②：`3×42＋3×8` → `3×(42+8)`。42と8で50を作る組は元の問題バンクに明示的に含まれています。`3×(42+8)`自体は元の意図に沿う正解です。修正対象は独自生成や追加段階でした。
- 交換・結合：`125×7×8` → `(125×8)×7`。
- かけ算のせいしつ：`5×2＝10` → `5×20＝□`。「新しい積は、もとの積の何倍？」→10倍。元の図を表示。
- 図形と式：2行6列を左右3列ずつ青・赤で囲む図 → `3×2＋3×2`。色順と囲み方も元のまま。

## 文章問題と式

この形式だけは独自生成です。えん筆とキャップ・おかしと袋・袋ごとにあめを取り出す・シール配り・買い物の残金・色紙の等分・箱の合計という7場面を用意。全部の代金／残り／1人分など、何を式にするかを明示しています。等分の答えは整数になる条件にしました。

例：「400円持っています。1こ15円のおかしを4こ買いました。残りのお金を表す式はどれ？」

選択肢：`400－15×4`（正解）、`(400－15)×4`、`400×4－15`。正解位置は変化します。

加数が等しいと誤答2個が同一になる場合も排除しました。全場面の生成選択パターンを走査し、3択が異なり、数値上も正解が1つ、答えが整数であることを確認しています。

## 検証

- 分配①全64問・1,024通りの2段階回答組合せを元のfinishと照合。

- 文章問題の生成選択パターン、正解の一意性、整数条件を検証。
- 30連続正解、2分間記録の分離、既存称号・所持品・ポイント保持、履歴容量・二重付与・保存容量不足時の回帰を確認。
