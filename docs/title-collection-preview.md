# 称号中心への移行：第1段階（確認用）

本番公開前に確認するための画面改修。`environments/preview.json` の `rankingsRetired` のみを有効にし、本番ルートのHTML・JS・設定とFirebase Rulesは変更しない。

- ホームのチャンピオンを、自分の称号の獲得数・公開対象の総数・教科別達成率へ置き換える。
- 横長のゲーム選択を、ゲーム名／正式称号／達成率／自己最高／プレイの順にする。高さの足りないiPadはページ送りにし、ゲームの表示を落とさない。
- 既存の4段階・6段階は承認に従って維持。達成率は実際の段階数を分母にする。正式画像のない既存2ゲームは元の文字称号を使い、画像を新作しない。
- 公開状態が読める管理対象はサーバーの状態で集計する。非公開の称号は保存したまま、集計対象から除外。既存確認用設定で静的に公開されているゲームは、その登録状態を引き継ぐ。設定読み取りに失敗した管理対象は集計・プレイ対象にしない。
- ランキングのHTML入口・同期スクリプトを確認用ビルドから外し、APIにも停止条件を入れる。過去のローカル・Firestoreランキングデータは削除しない。
- チャレンジ、出題モデル、称号条件、ポイント経済の正本は維持。総まとめゲームは現在の本番モデルを確認用に取り込み、既存の本番挙動を基準にする。
- 管理室のランキングに付随する参照・更新は停止するが、児童管理・個別公開設定・監査・バックアップは維持する。

保留中のランキングPR #53・#60は、今回の廃止方針を理由にクローズ。ブランチと過去データは残す。
