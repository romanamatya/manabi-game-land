既存30件に本番用の4件を追加し、計34件成功。元モデルの同一乱数5,000問、バンク全問、10,500問出題、操作、既存データ、履歴制限・保存容量不足を検証。本番用では既存カタログ全項目・ランキング設定の完全保持、確認用と出題コードの一致、実際の本番ポイント処理で二重付与なし・日次50pt・所持品と他教科ポイント保持、専用ランキングへのリンクを検証しました。

本番の環境設定・Firebase・認証・Firestoreルール・児童データは直接操作しません。本番のeconomy.jsとstorage-adapters.jsも保持し、回答履歴修復・重複防止・保存待ち処理を維持します。旧ランキングの一括リセットや他ゲームの2分間移行は実施しません。
